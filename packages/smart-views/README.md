# Smart Views

Smart Views lets you create your own tailored overview pages for your assets — without writing any
code. Instead of browsing through generic lists, you decide which assets to show and exactly which
details appear in the table.

## What you can do

### Build your own asset overviews

Create a smart view by choosing an asset type (for example pumps, meters or buildings) and selecting
the information you want to see for each asset. Every smart view shows up in the navigation menu with
its own name and icon, so the views your team needs are always one click away.

### Decide what each view shows

For every smart view you can:

- **Pick the asset type** it is based on, so the view automatically lists the right assets.
- **Choose an icon** that makes the view easy to recognise in the menu.
- **Select the columns** that appear in the table — such as name, description or any other detail —
  and give each column a clear heading. New views start with a sensible set of columns that you can
  adjust at any time.

### Manage everything in one place

A dedicated **Smart views** page (found under Settings) lists all the views that have been created.
From there you can:

- See all existing smart views at a glance, including their name and icon.
- **Add** a new view using the button in the toolbar.
- **Edit** a view to change its asset type, icon or columns.
- **Delete** a view you no longer need (you'll be asked to confirm first).

The list supports searching, sorting and paging, so it stays easy to use even with many views.

## Getting started

1. Open the **Smart views** page from the Settings area.
2. Select **Add configuration** in the toolbar.
3. Give your view a name, choose the asset type, pick an icon and set up the columns you want.
4. Save — your new smart view appears in the navigation menu, ready to use.
